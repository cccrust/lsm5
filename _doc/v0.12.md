## 新功能

### Config 擴展

```rust
let config = Config::new("./data")
    .scan_cache_size(32 * 1024 * 1024);  // scan 快取大小 (預設 32MB)
```

### ScanCache API

```rust
use lsm5::scan_cache::{ScanCache, ScanKey};

let mut cache = ScanCache::new(10);
let key = ScanKey { start: b"a".to_vec(), end: b"z".to_vec() };
cache.put(key.clone(), vec![1, 2, 3]);  // 儲存 sstable sequence 清單
assert_eq!(cache.get(&key), Some(vec![1, 2, 3]));

// 當 SSTable 被壓縮時，使相關快取失效
cache.invalidate_for_sstable(1);
```

### 快取策略

- 記住 scan 範圍對應的 SSTable 清單 (sequence numbers)
- 對於重複的 scan 範圍，可快速決定要讀取的 SSTables
- 支援 LRU 淘汰
- 壓縮時自動使涉及的快取失效

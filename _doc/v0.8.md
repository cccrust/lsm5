## 新功能

### Config 擴展

```rust
let config = Config::new("./data")
    .compression_enabled(true)      // 啟用壓縮 (預設 true)
    .compression_level(3);         // zstd 壓縮等級 1-22 (預設 3)
```

### 壓縮格式

```
┌─────────────────────────────────────┐
│ Data Block (壓縮後)                  │ <- zstd 壓縮
├─────────────────────────────────────┤
│ Index Block (保持未壓縮)            │
├─────────────────────────────────────┤
│ Bloom Filter (保持未壓縮)           │
├─────────────────────────────────────┤
│ Footer (40 bytes)                   │
│   [8] index_offset                  │
│   [8] bloom_offset                  │
│   [8] data_len (解壓後大小)         │
│   [8] compressed_len (壓縮後大小)   │
│   [8] magic                        │
└─────────────────────────────────────┘
```

### 壓縮策略

- 只壓縮 Data Block (key-value 資料)
- 閾值: 區塊 > 1KB 才壓縮
- Index/Bloom 保持未壓縮 (隨機讀取需要)

## 新功能

### Config 擴展

```rust
let config = Config::new("./data")
    .background_threads(2);  // 背景執行緒數量 (預設 2)
```

### BackgroundWorker API

```rust
use lsm5::background::BackgroundWorker;

let worker = BackgroundWorker::new(2);
worker.submit_flush(entries, seq);
worker.submit_compact(inputs, target_level);
```

### 說明

- 提供基礎設施，非同步任務框架就緒
- 可擴展至實際的 async flush/compaction
- 預留介面，未來可整合進 DB 結構

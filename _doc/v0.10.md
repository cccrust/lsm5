- [x] 73+ 測試通過

## 新功能

### Config 擴展

```rust
let config = Config::new("./data")
    .monitoring_enabled(true)    // 啟用監控端點 (預設 false)
    .monitoring_port(8080);     // 監控 port (預設 8080)
```

### API 端點

```
GET /         - 可用端點列表
GET /stats    - 數據庫統計 (operations, cache)
GET /cache    - 快取命中率
GET /health   - 健康檢查
```

範例輸出:
```bash
$ curl http://localhost:8080/stats
{"operations":{"reads":1500,"writes":1000,"flushes":5,"compactions":3},"cache":{"hits":150,"misses":50,"hit_rate":0.75}}

$ curl http://localhost:8080/health
{"status":"ok"}
```

## 新增 CLI 命令

```bash
lsm5 compact       # 手動觸發壓縮
lsm5 verify        # 驗證資料完整性
lsm5 import <file> # 匯入資料 (key:value 格式)
```

## test.sh 檢查流程

```bash
cargo test      # 執行所有測試
cargo clippy    # Lint 檢查
cargo fmt       # 格式檢查
```

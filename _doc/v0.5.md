## 新功能

### 事務 API

```rust
// 開始事務
db.begin();

// 在事務中寫入
db.tx_put("key1", "value1").unwrap();
db.tx_delete("key").unwrap();

// 提交事務
db.commit().unwrap();

// 或回滾
db.rollback().unwrap();
```

### 新增錯誤類型

- `TransactionError(String)` - 交易錯誤
- `NoActiveTransaction` - 無活躍交易
- `TransactionAlreadyCommitted` - 交易已提交

### 新模組

- `src/transaction.rs` - 交易邏輯

## 新功能

### Config 擴展

```rust
let config = Config::new("./data")
    .write_buffer_size(1024 * 1024)        // 1MB buffer
    .write_buffer_flush_threshold(512 * 1024);  // 512KB flush threshold
```

### 批次寫入 API

```rust
// 批次寫入多筆記錄，比單筆 put 更高效
db.write_batch(vec![
    ("key1", "value1"),
    ("key2", "value2"),
    ("key3", "value3"),
])?;
```

### 查詢計劃 API

```rust
// 分析 scan 查詢，產生最佳化計劃
let plan = db.analyze_scan(b"a", b"z");
println!("{}", plan);
```

輸出範例:
```
Scan Plan:
  Range: [a, z]
  Estimated keys: 10000
  Levels to scan: [999, 0, 1]
  Bloom filter: true
  Index: true
  Cost: Medium
```

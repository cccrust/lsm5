## 新功能

### Config 擴展

```rust
let config = Config::new("./data")
    .cache_size(64 * 1024 * 1024);  // 快取大小 (預設 64MB)
```

### 快取策略

- LRU 淘汰策略
- 快取 SSTable 解壓後的 data block (以 sequence number 為 key)
- 讀取時先檢查快取，未命中才讀取磁碟
- 快取大小可配置，預設 64MB

### 監控

`db.stats()` 現在包含:
- `cache_hits` - 快取命中次數
- `cache_misses` - 快取未命中次數
- `cache_hit_rate` - 快取命中率

範例輸出:
```
Cache:
  Hits:    150
  Misses:  50
  Hit Rate: 75.0%
```

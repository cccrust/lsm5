# v0.1 - LSM-Tree 基本實作完成

## 功能

- [x] MemTable (BTreeMap 記憶體緩衝區)
- [x] WAL (Write-Ahead Log) 含 CRC32 驗證
- [x] SSTable (磁碟有序資料表)
- [x] Bloom Filter (快速查詢)
- [x] Leveled Compaction (層級壓縮)
- [x] 基本 CRUD 操作 (put/get/delete/scan)
- [x] Crash Recovery (崩潰復原)

## 測試

- [x] 38 個單元測試
- [x] WAL 測試: 寫入/回放/空檔/二進位資料
- [x] Bloom Filter 測試: 無 false negative/FPR/empty/single item/from_raw
- [x] MemTable 測試: put/get/delete/overwrite/sorted iteration/drain/binary
- [x] Compaction 測試: k-way merge/dedup/tombstone dropping
- [x] DB 測試: 基本操作/flush/crash recovery/scan/sync/多值

## CLI 用法

```bash
cargo build --release
./target/release/lsm5 put <key> <value>
./target/release/lsm5 get <key>
./target/release/lsm5 del <key>
./target/release/lsm5 scan <start> <end>
./target/release/lsm5 stats
./target/release/lsm5 bench
```

## 架構

```
Write Path:
  put(key, value)
      ├─► WAL append (crash-safe)
      └─► MemTable (BTreeMap)
               │  (when size >= threshold)
               ▼
           L0 SSTable
               │  (when L0 count >= 4)
               ▼
           L1..LN SSTable

Read Path:
  get(key)
      ├─► MemTable
      ├─► L0..LN SSTables (with Bloom filter)
      └─► return value or None
```

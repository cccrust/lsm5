## 新功能

### 批次寫入 API

```rust
// 批次寫入多筆記錄
db.write_batch(vec![
    ("key1", "value1"),
    ("key2", "value2"),
])?;
```

### 緩衝寫入

```rust
let config = Config::new("./data")
    .write_buffer_size(1024 * 1024)  // 1MB buffer
    .write_buffer_flush_threshold(512 * 1024);  // 512KB 時 flush
```

### 查詢計劃

```rust
// 分析查詢，產生最佳化計劃
let plan = db.analyze_scan(b"a", b"z");
println!("{}", plan);
```

輸出:
```
Scan Plan:
  Range: [a, z]
  Estimated keys: 10000
  Levels to scan: L0, L1
  Index filter: Bloom + Index
  Cost: medium
```

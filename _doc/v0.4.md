## 新功能

### Iterator API

```rust
// 正向 Iterator
let iter = db.iterator(Some(b"start"), Some(b"end"));
for (key, value) in iter {
    println!("{} => {}", key, value);
}

// 反向 Iterator
let iter = db.reverse_iterator(Some(b"start"), Some(b"end"));
```

### LsmIterator 方法

```rust
iter.valid()           // 是否有效
iter.next()            // 前進
iter.prev()            // 後退
iter.key()             // 取得目前 key
iter.value()           // 取得目前 value
iter.seek(target)      // 搜尋
iter.seek_to_first()   // 移到開頭
iter.seek_to_last()    // 移到結尾
```

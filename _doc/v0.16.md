## 新功能

### 新錯誤類型

```rust
#[derive(Debug)]
pub enum Error {
    // ... existing
    DatabaseFull,           // 資料庫已滿
    MemoryExceeded,         // 記憶體超限
    SnapshotNotFound,       // Snapshot 不存在
    TaskCancelled(String),  // 任務被取消
}
```

### Panic Recovery

```rust
use lsm5::error::catch_panic;

// 安全地執行操作，捕獲 panic
let result = catch_panic(|| {
    db.put("key", "value")
});

match result {
    Ok(Ok(_)) => println!("成功"),
    Ok(Err(e)) => println!("錯誤: {}", e),
    Err(e) => println!("發生 panic: {}", e),  // Error::Corruption
}
```

## 新功能

### Config 擴展

```rust
let config = Config::new("./data")
    .l0_compaction_trigger(4)      // L0 壓縮觸發數
    .level_size_multiplier(10)    // 層級大小倍數
    .memtable_size_limit(4 * 1024 * 1024)
    .max_sstable_size(64 * 1024 * 1024);
```

### 監控指標

DbStats 現在包含:
- `reads` - 讀取次數
- `writes` - 寫入次數
- `flushes` - 刷新次數
- `compactions` - 壓縮次數

範例輸出:
```
=== LSM5 Database Statistics ===
MemTable: 100 entries, 524288 bytes
  L0: 2 SSTables, 1048576 bytes

Operations:
  Reads:     1500
  Writes:    1000
  Flushes:   5
  Compactions: 3
```

## 新功能

### SSTable 記錄格式 (含 CRC)

```
[4] key_len | [4] val_len | [1] is_tombstone | [4] crc32 | [N] key | [M] value
```

- 每筆記錄包含 4 bytes CRC32 校驗
- 讀取時自動驗證 CRC，損壞則回傳 `Error::Corruption`

### 錯誤處理

```rust
match db.get("key") {
    Ok(Some(v)) => println!("value: {:?}", v),
    Ok(None) => println!("not found"),
    Err(e) => match e {
        Error::Corruption(msg) => println!("資料損壞: {}", msg),
        _ => println!("其他錯誤: {}", e),
    }
}
```

## 新功能

### 效能計時

```rust
use lsm5::perf::Timer;

let mut timer = Timer::new();
db.put("key", "value")?;
println!("put took: {}μs", timer.elapsed_us());
```

### 效能統計追蹤

```rust
let mut stats = lsm5::perf::PerfStats::default();
let mut timer = lsm5::perf::Timer::new();

// 追蹤 put
timer.reset();
db.put("key", "value")?;
stats.record_put(timer.elapsed_us());

// 追蹤 get
timer.reset();
let _ = db.get("key")?;
stats.record_get(timer.elapsed_us());

println!("{}", stats.summary());
```

輸出:
```
Performance Summary:
  put:   avg 45μs, count 1
  get:   avg 12μs, count 1
  scan:  avg 0μs, count 0
  flush: avg 0ms, count 0
```
